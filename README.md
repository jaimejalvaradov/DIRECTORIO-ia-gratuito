# Directorio de IAs Gratuitas

Aplicación de consola en JavaScript que permite explorar y abrir distintas inteligencias artificiales gratuitas, organizadas por categoría.

Proyecto de evaluación del Módulo 3 - Fundamentos de programación en JavaScript (Alkemy).

## Cómo usarlo
1. Abrir `index.html` en el navegador
2. Presionar F12 para abrir la consola
3. Hacer clic en el botón "Iniciar programa"
4. Elegir un número del menú para abrir esa IA en una pestaña nueva, o "0" para filtrar por categoría
5. Escribir "S" para salir del programa

## Funcionalidades
- Listado de IAs con nombre, uso y categoría (arreglo de objetos)
- Apertura de sitios en pestaña nueva con `window.open()`
- Filtro por categoría (Texto, Imagen, Código, Estudio, Audio)
- Menú interactivo controlado con `while` y validación de opciones con `if`

## Tecnologías
HTML, CSS y JavaScript puro (sin librerías ni frameworks)
